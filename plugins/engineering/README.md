# engineering

A local plugin bundling Matt Pocock's engineering skills, cloned verbatim from
[mattpocock/skills](https://github.com/mattpocock/skills) (skills/engineering/).

## Skills

- **diagnose** — disciplined six-phase debugging methodology built around a fast feedback loop
- **grill-with-docs** — adversarial planning + ADR/context-doc updates
- **improve-codebase-architecture** — interface design, deepening modules, ubiquitous language
- **tdd** — red/green/refactor with companion guides on mocking, refactoring, deep modules, tests
- **to-issues** — convert plans into GitHub-style issues
- **to-prd** — generate a PRD from a working session
- **triage** — issue triage state machine (with `AGENT-BRIEF.md`, `OUT-OF-SCOPE.md`)
- **zoom-out** — context-expansion guide

## Omitted

`setup-matt-pocock-skills` was intentionally skipped — it's a per-repo bootstrap
flow specific to Matt's setup and not portable.
