description: Run the toy project's test suite and report a verdict.
---

Run the toy project's test suite and report honestly. Do not edit files.

1. Run `python3 -m pytest -q` from the repository root.
2. If it exits 0, report `**Verdict:** PASS` and stop.
3. If it exits non-zero, report `**Verdict:** FAIL` and list the failing test
   names from the output.

Report only the verdict line and the evidence that supports it.
